Sobre el Proyecto

Proyecto Expo Técnica 2026

Modernizando la seguridad y gestión escolar con IoT

SARGAP (Sistema de Acceso y Registro con Gestión Automatizada de Permisos) nació con el objetivo de reemplazar las planillas manuales en papel por una plataforma integral, rápida y auditable. Combina lectores RFID autónomos con una arquitectura cliente-servidor en tiempo real para administrar quién ingresa a cada sector de la institución.

📡

Hardware & IoT

Nodos lectores con microcontroladores ESP32, sensores RFID MFRC522 y reloj en tiempo real (RTC DS3231) con respuesta sonora y visual inmediata.

⚙️

Backend & Datos

API REST desarrollada en Java con Spring Boot y base de datos relacional PostgreSQL para validar permisos granulares por sala al instante.

💻

Gestión Web

Interfaz intuitiva y responsiva que permite auditar ingresos en vivo, capturar tarjetas nuevas y asignar roles o sectores sin conocimientos técnicos.

¿Qué resuelve SARGAP en la institución?

Control por Sector

Permite habilitar o restringir el paso de cada tarjeta según el rol (Alumnos, Docentes, Preceptores, Directivos) y el aula o laboratorio.

Trazabilidad Horaria

Gracias al módulo RTC con batería propia, cada lectura registra fecha y hora exacta incluso ante cortes temporales de red.
